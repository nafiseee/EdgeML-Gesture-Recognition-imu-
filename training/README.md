# EdgeML Gesture Recognition V2 (6DoF IMU)

Это логическое развитие первой версии проекта (MVP на базе магнитометра). Анализ первой версии показал, что магнитометру не хватает степеней свободы для понимания сложной пространственной геометрии, а электромагнитный фон помещения дает слишком много шума. 

**Отличия версии v2** Отказ от магнита на пальце и полный переход на профильное железо — **6-осевой IMU (Акселерометр + Гироскоп)**. 

Результат: нейросеть математически видит разницу между угловой скоростью и линейным смещением, точность на сложных паттернах (Telegram, Spotify, Circle) пробила 97%, а благодаря интеграции аппаратного прерывания энергопотребление системы в фоне сведено к нулю.

## Что нового в V2

* **Аппаратный триггер:** Непрерывный анализ осей высаживает батарею. В этой версии нативный C-демон перехватывает системный `dbtap` (двойной тап по корпусу смартфона). Скрипт инференса спит и запускает сбор окна (1.5 сек на 200 Гц) *только* после физического стука. Отсев ложных срабатываний в кармане — 100%.
* **GAP:** В архитектуре нейросети тяжелый слой `Flatten` заменен на `Global Average Pooling` (GAP). Матрица схлопывается усреднением по времени (`np.mean`), делая алгоритм независимым от того, в какую долю секунды внутри 300-кадрового окна начался жест. Веса модели ужались до ~5 КБ.
* **Локальный Z-score:** Данные нормализуются не глобально, а внутри каждого окна в реальном времени с центровкой гравитации. Для сети слабый взмах уставшей рукой и резкий агрессивный рывок выглядят математически идентично.

## 🛠 Технический стек

1. **Сбор данных (C + Termux + Flask):** Нативный демон `sensor_daemon.c` (через Android NDK API `ASensorManager`) читает акселерометр и гироскоп на частоте 200 Гц в обход виртуальной машины Java, исключая задержки GC. Сбор датасета организован через локальный Flask-сервер (`dataset_gui.py`) с UI, звуковой синхронизацией старта/стопа записи и отрисовкой на Chart.js.
2. **Аугментация (Time Series):** Применены физически обоснованные искажения в `pipeline.ipynb`. Добавлен сглаженный гауссовский шум (имитация тремора и термального дрейфа датчика). Временные сдвиги реализованы корректно — пустоты заливаются фоновым шумом, чтобы исключить артефакты и разрывы на границах сигнала.
3. **Обучение (PyTorch):** Написана кастомная, экстремально легкая 1D-CNN (2 сверточных блока + BatchNorm + MaxPool -> GAP -> Linear классификатор на 4 класса). Разделение на train/val сделано через `GroupShuffleSplit` (группировка по исходному жесту), что полностью исключает утечку данных (Data Leakage) при аугментации.
