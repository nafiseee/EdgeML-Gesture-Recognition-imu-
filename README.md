# EdgeML Gesture Recognition V2 (6DoF IMU)

Это логическое развитие первой версии проекта (MVP на базе магнитометра). Анализ первой версии показал, что магнитометру не хватает степеней свободы для понимания сложной пространственной геометрии, а электромагнитный фон помещения дает слишком много шума. 

**Отличия версии v2** Отказ от магнита на пальце и полный переход на профильное железо — **6-осевой IMU (Акселерометр + Гироскоп)**.


Результат: 1D-CNN на ~8 тыс. параметров (~31 КБ в float32), точность на валидации 98.4% (126 окон, 5 классов). Инференс работает на чистом NumPy на CPU телефона.

##Как это работает
sensor_daemon (C, 200 Гц) ──stdout──► infer.py (скользящее окно 300 кадров)
                                          │ фильтр амплитуды → нормализация → CNN (NumPy)
                                          ▼
                              am broadcast → MacroDroid (интент edge.gesture.DETECTED) 

## Что нового в V2

* **Непрерывный инференс и кнопка обратной связи:** от идеи с `dbtap` пришлось отказаться из-за аппаратных блокировок при движении. Сейчас C-демон непрерывно стримит данные IMU на 200 Гц, а `infer.py` анализирует скользящее окно в 300 кадров (1.5 с) с шагом 50 кадров, поэтому отдельный триггер для запуска жеста не нужен. Физическая кнопка **Volume Up** используется для обучения на ошибках. Отдельный поток демона читает `/dev/input/event*` напрямую из ядра и при нажатии печатает маркер `>>> FALSE_POSITIVE <<<`. Если нажать в течение 15 секунд после ложного срабатывания, последнее окно сохраняется в банк жёстких негативов (`dataset_HARD_NEGATIVES.csv`) и учитывается при следующем обучении.
* **GAP:** тяжёлый слой `Flatten` заменён на `AdaptiveAvgPool1d(2)`. Карта признаков усредняется по времени (`np.mean`), поэтому результат не зависит от того, в какой момент внутри 300-кадрового окна начался жест. Модель весит около 8 тыс. параметров (~31 КБ в float32).
* **Локальный Z-score:** данные нормализуются не глобально, а внутри каждого окна в реальном времени. Сначала вычитается среднее первых 10 кадров (центровка гравитации и смещения), затем идёт z-score по каждому каналу.

## 🛠 Технический стек
* **Классы** задаются в `datasets/buttons.json` (сейчас: Telegram, Circle, Circle_Rev, YouTube) плюс всегда присутствующий `0: Background`. Всего 5 классов.
* **Нормализация окна:** вычитание среднего первых 10 кадров (центровка гравитации и смещения), затем z-score по каждому каналу внутри окна. Слабый взмах уставшей рукой и резкий рывок выглядят для сети одинаково. Та же математика продублирована в инференсе.
* **Разбиение:** `StratifiedShuffleSplit` (80/20) выполняется **до** аугментации, поэтому копии одного жеста не попадают одновременно в train и val (утечки нет).
* **Аугментация (только train, ×4):** оригинал; сглаженный гауссов шум (имитация дрейфа наклона и тремора); временной сдвиг 20–50 кадров с заливкой краёв фоновым дрейфом вместо нулей; искажение времени (сжатие или растяжение сплайном). Выравнивание по `class_weight` в функции потерь.
* **Модель `EdgeCNN_v6`:** 4 свёрточных слоя (Conv1d + BatchNorm + ReLU, два MaxPool) → `AdaptiveAvgPool1d(2)` → Dropout → Linear. Глобальное усреднение по времени делает результат независимым от положения жеста внутри окна. Оптимизатор AdamW, лучший чекпоинт выбирается по минимальному Val Loss.
* **Экспорт:** веса в `outputs/weights.npz`, а прямой проход (`conv1d`, `batchnorm1d`, `maxpool1d`, `softmax`) генерируется функцией `export_numpy_math` в `outputs/model_math.py`. ONNX и TFLite не нужны.
* **Инструменты:** `training/gallery_builder.py` строит HTML-галерею всех жестов по классам для ручной чистки датасета (`TRASH_IDS` в ноутбуке).

## Быстрый старт (Termux + root)
 
1. Скомпилировать `sensor_daemon.c` через NDK в `daemon/sensor_daemon` 
```clang daemon/sensor_daemon.c -o daemon/sensor_daemon -landroid -lpthread```
2. Отредактировать buttons.json, записать жесты: запустить `python data_collection/dataset_gui.py` и открыть `http://<ip-телефона>:5000`. Выбрать класс, после сигнала сделать жест (запись 1.5 с), посмотреть график и сохранить или отменить.
3. Обучить модель в `training/pipeline.ipynb` (создаются `outputs/weights.npz` и `outputs/model_math.py`).
4. Запустить `python edge_inference/infer.py`. В MacroDroid настроить триггер на интент `edge.gesture.DETECTED` (параметр `name` содержит название жеста).
